Framing Neo-Riemannian transformations as acting on attributes rather than simply on pitches themselves,
this program shows the descriptive power of a 'subjective' approach. The axis of inversion is transformed along with the
pitch collection and the orientation is multiplied by -1.

A pitch collection here is an Object Class with 3 attributes: a prime form, orientation (clockwise or counter), and pitch_offset (transposition)

Just modify whether it is p, l, or r in the last line of code to change how it is transformed, or edit any parameter of the object itself in line 35!
